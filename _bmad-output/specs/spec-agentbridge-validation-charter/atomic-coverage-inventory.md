# Atomic coverage inventory — OQ-3A revised proposal

Статус: **OQ-3A frozen by Project Owner on 2026-09-13; OQ-3B closure evidence pending**.

Этот inventory раскладывает frozen EI-01–EI-25 на неделимые проверяемые обязательства. ID стабилен: `AC-EIxx-Pn` — обязательный положительный результат, `AC-EIxx-Nn` — отдельный falsifier. OQ-3B обязан связать каждый применимый atom с exact vector и evidence либо с заранее принятой candidate-neutral причиной исключения, сужающей общий claim.

## Coverage types and closure

- `P` positive; `N` negative; `B` boundary; `A` adversarial; `S` state/lifecycle; `F` fault/concurrency; `M` metamorphic.
- Каждый `P` получает `P` и хотя бы один `B/S/M`, каждый `N` — `N` и применимые `A/F/M`. Safety/privacy atom всегда получает минимум `N+B+A` и применимый `F/M`.
- Два atom можно покрыть одним vector только если один stimulus действительно активирует оба механизма, observers различают оба результата, а удаление любой проверки сделает vector недостаточным. Общая формулировка, одинаковый status или экономия числа тестов не создают эквивалентность.
- Не применимость определяется только общей frozen predicate до Candidate design. Невозможность кандидата выразить atom — его результат, а не исключение.
- Structural floor из 65 cells не заменяет inventory. Условие OQ-3B: **0 непокрытых применимых MUST/safety atoms**.

### PRD clause closure

Frozen PRD FR-1–FR-95 и применимые NFR входят в inventory не только через ссылки EI. Для каждого нормативного предложения используется стабильный адрес `AC-PRD-{FR|NFR}{number}-S{sentence}-C{clause}`: sentence считается в порядке исходного frozen requirement, а отдельные conjunction/list items получают собственный `C`. Отрицание, boundary, exception и failure consequence всегда отдельны; слова «и/либо» не разрешают объединять разные механизмы. Digest PRD фиксирует адреса. В OQ-3B, до OQ-2B/Candidate design, Conformance Lead создаёт механический clause index и два независимых reviewer подтверждают, что каждый safety/MUST clause либо связан с одним из frozen EI atoms выше, либо добавлен как новый AC atom без изменения смысла. Непривязанный clause блокирует OQ-2B и Candidate design. Candidate capability, будущая архитектура и число удобных тестов не участвуют в atomization.

## Threat/operator grammar closure

В дополнение к DS-6 OQ-3B обязан иметь typed operators для `CONTROLLER_COMPROMISE`, `CREDENTIAL_COMPROMISE`, `PARTICIPANT_COMPROMISE`, `INTERMEDIARY_COMPROMISE`, `COLLUSION`, `ENUMERATE`, `FALSE_PROVENANCE`, `NUMERIC_AMBIGUITY`, `UNICODE_AMBIGUITY`, `CANONICALIZATION_SPLIT`, `COMPRESS_BOMB`, `PARSER_DEPTH`, `EARLY_DATA_REPLAY`, `FALLBACK_WEAKEN`, `OPTIONAL_DEPENDENCY_REMOVE`, `OBSERVER_COMMON_MODE` и `NEW_THREAT`.

Условные transport/encoding operators применяются только когда соответствующий риск присутствует в общем frozen claim scope. Отсутствие такой функции не создаёт штраф только по candidate-neutral predicate, принятой до Candidate design; она симметрично ограничивает итоговый claim.

## OQ-3B closure report

Manifest OQ-3B обязан перечислить каждый EI-derived и PRD-clause AC ID, exact vector IDs, применённые coverage types, observers, oracle version и результат независимого cross-check. Любой пропуск, позднее объединение неэквивалентных atom или candidate-specific exclusion блокирует confirmatory run.
